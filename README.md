# 🐱 Cat API App

React-приложение для просмотра случайных изображений котиков с [thecatapi.com](https://thecatapi.com/).

## 🚀 Запуск проекта

1. **Клонировать репозиторий**

```bash
git clone https://github.com/sakenpolatov/cat-api-app.git
cd cat-api-app
```

2. **Установить зависимости**

```bash
npm install
```

3. **Создать файл `.env` в корне проекта со следующим содержимым:**

```env
REACT_APP_CAT_API_URL=https://api.thecatapi.com/v1/images/search
```

4. **Запустить проект**

```bash
npm start
```

После запуска открой [http://localhost:3000](http://localhost:3000) в браузере.
